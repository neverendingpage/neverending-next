# neverending.page

A page written by all of humanity, one word at a time.

## About

neverending.page is a collaborative article written by people from around the world. Every person gets one word, forever. No more, no less.

## Tech Stack

- TypeScript
- Tailwind CSS
- PostgreSQL
- AWS
